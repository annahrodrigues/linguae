# Linguae UI Kit 1.0

Protótipo frontend navegável e responsivo, baseado no `Linguae_Brand_Kit_1.0.pdf` (9 páginas).

## Como abrir
Abra `index.html` em um navegador moderno. Não é necessário instalar dependências nem executar servidor. As fontes Outfit e DM Sans são carregadas do Google Fonts quando houver conexão; sem internet, o navegador usa fontes alternativas.

## Inclui
- Dashboard desktop/mobile com cards de progresso, XP, sequência, lições e caminho de aprendizado.
- Biblioteca de botões, inputs, cards, validação, progress bars, tokens e gamificação.
- Exercício interativo de vocabulário com três perguntas e feedback imediato.
- Tela de conquistas desbloqueadas e em andamento.
- Mascote oficial reaproveitado do kit de identidade visual anterior.
- CSS tokens no topo de `styles.css`, navegação e interações em `script.js`.

## Referência e limites
Paleta, tipografia, raios, espaçamento, tom de voz e princípios de gamificação seguem o Brand Book 1.0. O monograma definitivo “Hidden Chameleon L” com olho visível ainda depende de arte final, como indica o documento; por isso a navegação usa um marcador provisório, não um logotipo oficial. Os dados de dashboard, exercícios e conquistas são demonstrativos, sem backend ou persistência. Não é um arquivo Figma nem um conjunto de SVGs vetoriais.
